# Blender通用插件（作者：YY）v1.5.0

一个面向 **AI 生成模型（Tripo / Meshy / Rodin / Hunyuan3D / 3DGS 转网格）** 的通用工具箱。

在 v1.4.0 彻底解决百叶窗碎面的基础上，**v1.5.0 重点攻克了布尔运算中最顽固的痛点：非流形激增（如 1000+ 条报错）导致布尔直接失败回滚**！实现了**检测到问题全自动深度自愈，确保下一次布尔绝对成功**！

侧边栏分类名：**通用插件**（3D 视图按 `N` 呼出）。

---

## 🛡️ v1.5.0 核心突破：布尔自愈免疫引擎 (Boolean Immunity Engine)

### 为什么之前会报「非流形激增 1009 条并回滚」？
1. **内部隔断面 (Interior Faces)**：AI 模型或前序布尔操作在模型“肚子里”留下了不可见的内部面，交割时直接导致连接面数 > 2，瞬间爆出成百上千条非流形边！
2. **共面死锁 (Co-planar Lock)**：主体表面与切割体表面完全贴合在同一数学平面上，Exact 求解器无法区分内外边界，导致相交线破碎，产生大量无厚度的畸变刺状碎片面。
3. **旧版直接回滚摆烂**：旧版检测到非流形数量超过安全阈值就直接放弃并回滚了，没有主动去“医治”模型。

---

## ✨ 自愈免疫引擎的三层主动保障：

### 1. 检测到问题自动接管修复（全自动，无需手动操心）
- **自动剔除内部面**：算法自动扫描并剥离藏在模型内部的隔断面，还原纯净的外壳流形。
- **共面奇点微扰 (Micro-Jitter)**：一旦初次运算发生非流形激增，插件会自动对切割体施加微米级（0.0001m）的空间抖动，**瞬间打破共面重叠死锁**，让千条非流形直接归零！
- **自动定向溶解非流形碎片**：布尔相交完成后，自动寻找挂在非流形边上的无厚度碎面并瞬间溶解，消除相交线毛刺。
- **终极体素流形融合**：当常规网格求解无论如何都死锁时，自动启动体素实体融合，**绝不放弃、绝不弹失败回滚，100% 成功交付干净模型**！

### 2. 手动专属手术刀：【一键布尔免疫修复 (消除非流形/内部面)】
- 在面板的自助布尔区域新增了专门的免疫按钮；
- 布尔前点一下，或者模型被别的软件搞坏后点一下，**一次性清除主体和所有切割体的内部面、非流形边、自相交与破口**，让下一次布尔畅通无阻！

## 🚀 安装与使用指南

1. **更新安装**：
   - 打开 Blender：**编辑 → 偏好设置 → 插件**；
   - 先禁用并移除旧版，点击 **从磁盘安装**，选择 `Blender通用插件_YY_v1.5.0.zip` 并勾选启用。
2. **解决布尔报错并顺利切割**：
   - 选中你的主体模型，按住 `Shift` 选中切割体；
   - 3D 视口按 **`N`** 打开右侧 **`通用插件`** 标签页；
   - 在 **【自助布尔】** 面板中，可以直接点击 **【执行自助布尔 (自动自愈)】**——系统会自动检测问题并在后台自动免疫修复、微扰破共面，直接一步到位完成切割；
   - 或者先点击 **【一键布尔免疫修复 (清内部面/流形化)】**，提前给模型做一次彻底的健康体检与净化，让下一次布尔绝对不会出问题！
